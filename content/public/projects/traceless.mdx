Personal data in India passes through a long chain of apps, brokers and agencies. Traceless helps one household see where theirs went and ask for it back.

It runs on Cloudflare Workers with Hono, D1, KV and R2, and fails closed. Every request needs a valid Access JWT. Automation drafts each removal request, and a person approves it before it leaves.
